# Инструкции для агента

- Пользователь сам делает скриншоты. Если для работы или проверки нужен скриншот, попроси пользователя его сделать и предоставить.
- Пользователь сам распаковывает архивы. Не распаковывай архивы самостоятельно; при необходимости попроси пользователя сделать это.
- Если нужная программа не установлена или недоступна, не устанавливай её самостоятельно. Останови связанное действие и спроси у пользователя, что делать дальше.
- Когда для проверки приложения нужен веб-сервер, попроси пользователя запустить его и проверить результат. Не запускай веб-сервер самостоятельно.
