# Engine3

Среда для постановки и съёмки сцен с клиент-серверной архитектурой. Сервер обрабатывает PMX и состояние сцены, а браузерный клиент отображает 3D и предоставляет Web UI. Текущий прототип сервера работает на Windows; долгосрочной целью является кроссплатформенность.

## Первый milestone

**Вывести PMX-модель с текстурами в браузерной 3D-сцене и предоставить простой Web UI для управления отображением.**

Это первый сквозной прототип, а не редактор и не полноценный игровой движок. Он должен проверить совместную работу серверной части на C3 и Python/pymeshio с клиентской частью на JavaScript и GLES/WebGL2.

### Ожидаемый результат

Браузерный клиент подключается к серверу и показывает:

- PMX-модель с геометрией, материалами и текстурами;
- 3D-сцену с рендерингом через GLES/WebGL2;
- простую камеру с возможностью повернуть и приблизить модель;
- панель Web UI.

Web UI позволяет:

- выбрать и загрузить PMX-модель;
- включить и выключить вращение модели;
- сбросить положение камеры;
- увидеть состояние загрузки и сообщение об ошибке.

Нативный viewport, нативное OpenGL-окно и встраивание браузера в него не требуются: вся клиентская визуализация выполняется в браузере.

### Архитектура

```text
Сервер:
PMX → Python + pymeshio → внутренние данные модели → состояние сцены
C3 → управление приложением и Python → обмен данными с клиентом

Клиент:
HTML + JavaScript + GLES/WebGL2 → 3D-сцена и Web UI

Взаимодействие:
Сервер → данные модели и состояние сцены → браузер
Web UI → команды → сервер → обновлённое состояние → Web UI
```

#### Серверная часть

- **C3** управляет жизненным циклом приложения, встроенным Python и обменом данными.
- **Python Embedded** хранит состояние между вызовами и предоставляет сетевой scene server.
- **pymeshio** будет использоваться для загрузки PMX и преобразования модели во внутренние данные.
- **HTTP и Server-Sent Events** используются в текущем прототипе для передачи состояния клиенту. При необходимости транспорт может быть расширен для команд клиента и бинарных буферов.

#### Клиентская часть

- **HTML, CSS и JavaScript** реализуют интерфейс без внешних фреймворков.
- **GLES на стороне браузера через WebGL2** выполняет рендеринг меша, материалов и текстур.
- Клиент получает массивы вершин от сервера и обновляет GPU-буферы без перезагрузки страницы.

Платформенные зависимости сервера должны быть изолированы, чтобы впоследствии заменить текущие Win32-вызовы кроссплатформенной реализацией.

### Обязательная часть

- Загрузка хотя бы одной реальной PMX-модели через Python/pymeshio.
- Передача геометрии, материалов и текстур от сервера браузерному клиенту.
- Вершинные и индексные буферы на стороне клиента.
- UV-координаты, базовые материалы и текстуры.
- Простой GLES/WebGL2-шейдер с освещением или базовой диффузной составляющей.
- Общий командный слой для Web UI и серверной части.
- Понятная диагностика ошибок загрузки модели и текстур.
- Корректное освобождение ресурсов при завершении работы.

### Не входит в milestone

- Pose Lab и редактирование скелета.
- VPD, VMD и анимация.
- Морфы и выражения лица.
- События, NPC и поведение.
- Сохранение сцен и undo/redo.
- Сложные материалы, тени и постобработка.
- Мультиплеер.
- Одновременная поддержка всех целевых серверных платформ уже в первом milestone.
- Полноценная библиотека ассетов.

### Критерий завершения

Milestone считается выполненным, когда сервер загружает реальную PMX-модель через Python/pymeshio, передаёт её браузерному клиенту, а клиент показывает модель с текстурами в GLES/WebGL2-сцене и позволяет управлять отображением через Web UI. Команды Web UI и вызовы серверной части приводят к одинаковому изменению состояния сцены.

## Текущее состояние

- Реализована динамическая загрузка Python Embedded и вызовы функций Python из C3.
- C3 умеет передавать скалярные значения, строки и типизированные массивы.
- `PySceneModule` запускает и останавливает scene server, добавляет вершины и вызывает `think()` в главном цикле.
- Python хранит куб, принимает дополнительные вершины и рассылает полный снимок меша через SSE.
- Браузерный WebGL2-клиент отображает вращающийся куб и добавленный из C3 треугольник с освещением и шахматной текстурой.
- Python scene server работает автономно и позволяет добавлять треугольники через консоль.
- Загрузка PMX/pymeshio и передача материалов и текстур ещё не реализованы.

## Запуск текущего прототипа

```bash
c3c build
./build/whisper2.exe
```

Откройте `http://127.0.0.1:8000` в браузере. Нажатие **Escape** завершает серверное приложение.
